# TV de Anúncios

Página que toca sem parar os comerciais de TV no ar nos EUA, com anunciante, título e agência criativa.

- Lista e agência: iSpot.tv
- Vídeo: YouTube (canal oficial sempre que possível); quando não há, a versão do iSpot
- `dados.json` é atualizado todo dia pelo robô em `.github/workflows/atualizar.yml` (dá para rodar na mão em Actions → "Atualizar comerciais" → Run workflow)
